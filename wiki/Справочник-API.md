# Справочник: API

> Относится к версии 1.76.0 · проверено 2026-10-26 · уровень проверки 2 (маршруты и OpenAPI сверяются тестом; описание вручную сокращено)

*Тип страницы: справочник.*

Базовый путь: `/api/v1`. Формат — JSON. Схемы запросов и ответов — в пакете `packages/contracts`. Машиночитаемое описание (OpenAPI 3.1) публично: `GET /api/v1/openapi.json`. В нём описаны операции, которыми пользуются токены API и консольный клиент: сейфы, дерево, записи (чтение, создание, изменение, корзина), история, журнал ключей. Соответствие маршрутов описанию проверяется тестом.

Записи приходят шифртекстом: API не отдаёт открытых данных ни с одним токеном.

## Аутентификация

| Способ | Заголовок | Префикс |
| --- | --- | --- |
| Сеанс браузера | `Authorization: Bearer aks_…` | `aks_` |
| Токен API | `Authorization: Bearer akt_…` | `akt_` |

Токены хранятся на сервере как SHA-256. Токен API ограничен: управление учётной записью, сеансы, второй фактор, другие токены и административные маршруты недоступны (403 `token_not_allowed`). Операции импорта и экспорта, начатые через `/audit/event`, токенам API недоступны.

## Формат ошибки

```json
{ "error": { "code": "version_conflict", "message": "…", "requestId": "…", "details": null } }
```

Сообщения не содержат секретов и не повторяют присланные значения.

| Код HTTP | `code` |
| --- | --- |
| 400 | `validation_error`, `weak_kdf` |
| 401 | `unauthorized`, `invalid_credentials` |
| 403 | `forbidden`, `registration_closed`, `chief_required`, `token_not_allowed` |
| 404 | `not_found` (не участнику сейф неотличим от несуществующего) |
| 409 | `already_exists`, `version_conflict`, `stale_key_version` |
| 429 | `too_many_attempts` (заголовок `Retry-After`) |

## Система

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/health` | процесс жив |
| GET | `/ready` | готовность (доступна БД), 503 при сбое |
| GET | `/version` | версия, сборка, канал обновлений |

## Учётные записи и сеансы

| Метод | Путь | Доступ | Описание |
| --- | --- | --- | --- |
| GET | `/auth/registration` | публичный | можно ли создать учётную запись |
| GET | `/auth/params?email=` | публичный | параметры Argon2id (для неизвестных адресов — правдоподобные значения) |
| POST | `/auth/register` | публичный | регистрация; первая запись — администратор |
| POST | `/auth/login` | публичный | вход по `authKey`; ограничение попыток |
| POST | `/auth/logout` | сеанс | завершить сеанс |
| GET | `/auth/me` | сеанс | текущий пользователь |
| GET / DELETE | `/auth/sessions`, `/auth/sessions/:id` | сеанс | список и завершение |
| POST | `/auth/sessions/revoke-others` | сеанс | завершить остальные |
| POST | `/auth/change-password` | сеанс | смена пароля разблокировки сейфов |
| POST | `/auth/recovery/start`, `/auth/recovery/complete` | публичный | восстановление по ключу |

## Сейфы и записи

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/vaults` | сейфы пользователя с запечатанным для него ключом |
| GET | `/vaults/:vaultId/entries` | записи сейфа |
| POST | `/vaults/:vaultId/entries` | создать (`id` задаёт клиент) |
| GET | `/vaults/:vaultId/entries/:entryId` | получить |
| PUT | `/vaults/:vaultId/entries/:entryId` | изменить; `expectedVersion` обязателен |
| DELETE | `/vaults/:vaultId/entries/:entryId?expectedVersion=` | в корзину |

Административные, интеграционные и служебные маршруты (около 270 обработчиков в `apps/api/src/routes`) в справочник и в OpenAPI не включены: описание в `apps/api/src/openapi.ts` не содержит административных путей (уровень 1). Их контракт — схемы в `packages/contracts`. Публичный стабильный интерфейс для интеграций — клиентский, перечисленный выше.
