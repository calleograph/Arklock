# Сопровождение вики

> Относится к версии 1.83.0 · проверено 2026-10-28 · уровень проверки 2 (проверка ссылок запускалась автором; публикация в репозиторий вики не выполнялась)

*Тип страницы: практическое руководство.*

Для кого: владелец репозитория и участники. Результат: вики опубликована и обновляется при каждом выпуске.

## Как это устроено

Вики GitHub хранится в отдельном git-репозитории `calleograph/Arklock.wiki.git` и не поддерживает pull request. Поэтому исходники лежат в каталоге `wiki/` основного репозитория, проходят те же проверки, что и код, и копируются в репозиторий вики при выпуске.

Если нужны обязательное ревью документации и сборка в CI, лучше подойдёт каталог `docs` с публикацией через GitHub Pages.

## Первая публикация

Репозиторий вики появляется после сохранения первой страницы в веб-интерфейсе.

1. В настройках репозитория («Settings → Features») включите «Wikis». Рекомендуется ограничить правку пользователями с правом записи.
2. Откройте вкладку «Wiki» и сохраните первую страницу `Home` с любым текстом.
3. Клонируйте репозиторий вики рядом с основным и скопируйте файлы:

   ```bash
   git clone https://github.com/calleograph/Arklock.wiki.git ../Arklock.wiki
   rsync -a --delete --exclude .git wiki/ ../Arklock.wiki/
   cd ../Arklock.wiki
   git add -A
   git status
   git commit -m "Вики: обновление до версии 1.83.0"
   git push
   ```

   Ожидаемый результат: страницы доступны на вкладке «Wiki», боковая и нижняя панели отображаются.
4. Откройте страницы с кириллическими именами и скриншотами и проверьте, что ссылки и изображения работают, а диаграмма Mermaid отображается.

> **Предупреждение.** Не используйте `git push --force` в репозитории вики: история правок нужна для отката.

Команды публикации в этой вики автором не запускались: репозиторий вики не существует.

## Проверка перед публикацией

```bash
node scripts/check-wiki.mjs
node scripts/check-private-data.mjs
```

`check-wiki.mjs` проверяет внутренние ссылки между страницами, ссылки на изображения, наличие строки версии и даты вверху каждой страницы, отсутствие страниц без ссылок из боковой панели и ссылок на несуществующие страницы. Орфографию проверьте отдельно, например в редакторе.

## Обновление при выпуске

1. Измените версию и дату проверки на каждой странице: строка «Относится к версии X, проверено ГГГГ-ММ-ДД» (замена командой `sed -i`).
2. Сверьте со свежими фактами страницы, у которых изменился источник:

   | Страница | Источник в коде |
   | --- | --- |
   | Справочник: конфигурация | `apps/api/src/config.ts`, `compose.yaml`, `install.sh` |
   | Справочник: роли и права | `apps/api/src/perms.ts` |
   | Справочник: скрипты | `install.sh`, `scripts/*.sh` |
   | Справочник: API | `packages/contracts`, `apps/api/src/routes` |
   | Справочник: журнал событий | `apps/api/src`, `event-level.ts` |
   | Состояние функций | `docs/FEATURE_STATUS.md` |
   | Скриншоты | `node scripts/screenshots.mjs` и ручная проверка |
   | Планы и ограничения | `PROJECT.md`, `docs/REQUIREMENTS_ACCEPTANCE.md` |

3. Запустите проверки и скопируйте в репозиторий вики.
4. Обновите нижнюю панель `_Footer.md`.

Правило: факт описан в одном месте, в остальных стоит ссылка.
