# Как импортировать и экспортировать пароли

> Относится к версии 1.88.0 · проверено 2026-10-28 · уровень проверки 2 (`services.test.ts`, `transfer-policy.test.ts`, `workspace.spec.ts`)

*Тип страницы: практическое руководство.*

Для кого: **главный администратор**. Результат: записи загружены в сейф либо выгружены в файл. Нужно заранее: быть главным администратором, иметь ключ нужного сейфа и право создавать в нём записи (для импорта).

Раздел «Администрирование → Сейфы и пространства → Импорт и экспорт» (`/admin/transfer`) виден только главному администратору. Остальным ролям (сотрудник, администратор сейфа, делегированный и обычный полный администратор) раздела нет, а сервер отклоняет начало операции ответом 403; API-токены тоже получают отказ. Операция идёт в браузере: файл уходит на сервер только при сохранении записей в сейф.

> **Граница защиты.** Сервер не может отличить запись импортированных строк от обычного создания записи: шифрование выполняет браузер. Право проверяется на старте операции. Ручные обращения к API записей остаются под правами сейфов.

## Импорт

1. Выберите пространство и сейф.
2. Выберите файл. Формат определяется сам и меняется вручную: CSV, Bitwarden JSON, Passwork JSON, KeePass XML (KeePass 2), JSON Arklock, зашифрованный архив Arklock (потребуется пароль архива).
3. Для CSV сопоставьте столбцы с полями записи. Отметка «Пропустить первую строку (заголовки)» ставится автоматически.
4. Прочитайте предпросмотр: число записей, дубликатов, вложений и замечания. Дубликат — запись с тем же названием, логином и адресом. По умолчанию они пропускаются.
5. Нажмите «Импортировать». Ожидаемый результат: итог «создано, пропущено, ошибок».

Существующие записи не изменяются. Папки создаются по пути из файла.

| Формат | Папки | TOTP | Доп. поля | Вложения |
| --- | --- | --- | --- | --- |
| JSON Arklock и архив | да, со значками | да | да | да |
| Bitwarden JSON | да (вложенность через «/») | да | да | нет |
| Passwork JSON | да | да | да | нет |
| KeePass XML | да (группы) | как доп. поле | да | нет |
| CSV | по столбцу «Папка» (`А/Б/В`) | по столбцу | нет | нет |

Bitwarden: переносятся логины и защищённые заметки; карточки и удостоверения полноценно не создаются. Зашифрованную выгрузку Bitwarden Arklock не читает: выгрузите без шифрования, импортируйте и удалите файл. Максимальный размер файла — 200 МБ.

## Экспорт

1. Выберите область: один сейф, все сейфы пространства или все доступные.
2. Выберите формат:
   - **Зашифрованный архив** (рекомендуется): пароль из 30 случайных знаков создаётся автоматически, показывается перед выгрузкой; есть «Копировать» и «Создать новый». Сохраните его отдельно от файла. Восстановить нельзя.
   - **JSON** и **CSV** — открытый текст; нужна отметка «Я понимаю риск».
3. При необходимости включите вложения (до 20 МБ каждое и 128 МБ в сумме; остальные пропускаются, число сообщается).
4. Нажмите «Выгрузить».

Выгружается только то, что вам разрешено читать и к чему у вас есть ключ. Роль главного администратора ничего не расширяет: чужие личные сейфы и сейфы без выданного ключа недоступны. В журнал попадают формат и число записей, но не пароль архива и не содержимое.

> **Предупреждение.** Открытые выгрузки содержат пароли. Удаляйте файлы после использования.

Формат архива и расшифровка вне Arklock — [Справочник: форматы данных](Справочник-форматы-данных).

## Типичные ошибки

| Сообщение | Что делать |
| --- | --- |
| «Неверный пароль архива или повреждённый файл» | Проверьте пароль. Если верный — файл повреждён: возьмите исходный |
| «Файл больше 200 МБ» | Разделите выгрузку по сейфам |
| «У вас нет права добавлять записи ни в один сейф» | Попросите владельца выдать роль не ниже «Редактор» |
| Дубликаты пропущены, а нужны | Снимите отметку «Пропускать дубликаты» |
