# Глоссарий

> Относится к версии 1.86.0 · проверено 2026-10-28 · уровень проверки 1

*Тип страницы: справочник.*

| Термин | Значение |
| --- | --- |
| Arklock | Корпоративный менеджер паролей для самостоятельного размещения |
| Пароль разблокировки сейфов | Секрет, из которого в браузере выводятся ключи шифрования. У локальной учётной записи он же пароль входа; при входе через каталог, SSO или SAML — отдельный пароль. Сервер его не знает |
| Ключ восстановления | Код, который показан при регистрации один раз. Возвращает доступ при потере пароля разблокировки сейфов |
| Корпоративное восстановление | Процедура организации: зашифрованный офлайн-пакет для заранее подключённых сейфов |
| Сейф | Контейнер записей с общим ключом и набором участников |
| Пространство | Объединение сейфов и список тех, кто его видит. Бывает общедоступным и закрытым. Членство в пространстве ключ сейфа не выдаёт |
| Организация | Корпоративное пространство и сейф, созданные при установке |
| Запись | Зашифрованный элемент сейфа: логин, пароль, адрес, заметки, файлы, TOTP |
| Папка | Раздел сейфа; может быть вложенной |
| Группа | Набор сотрудников для выдачи доступа; может быть привязана к группе каталога |
| Подразделение | Группа, закрытое пространство, сейф отдела и сейф руководства, созданные мастером |
| Главный администратор | Администратор с флагом `chief`: назначает полных администраторов, выполняет импорт и экспорт, видит обзор организации |
| Полный администратор | Администратор всех разделов панели |
| Делегированный администратор | Администратор с административной ролью на отдельные разделы |
| Хранитель ключа | Активный участник сейфа с текущим ключом, чтением записей и правом выдавать ключи |
| Выдача ключа | Подписанная передача ключа сейфа участнику; её выполняет клиент уполномоченного участника |
| Ротация, смена ключа | Создание новой версии ключа сейфа и перешифровка данных |
| Журнал ключей | Хэш-цепочка открытых ключей пользователей, которую проверяет клиент |
| Помощник обновлений | Служба systemd, которая выполняет обновление, откат и копии по запросу панели |
| Профиль `standalone` / `shared-host` | Установка на отдельный сервер / на сервер с другими приложениями |
| PWA | Веб-приложение, установленное на главный экран телефона |
| TOTP | Одноразовые коды по времени (RFC 6238) |
| WebAuthn | Ключи безопасности и ключи доступа |
| LDAP, LDAPS | Протокол каталога пользователей; LDAPS — с TLS |
| OIDC | OpenID Connect, протокол единого входа |
| SAML | Протокол единого входа SAML 2.0 |
| SIEM | Система сбора и анализа событий безопасности |
| Argon2id | Функция вывода ключа из пароля |
| AES-256-GCM | Алгоритм шифрования с проверкой целостности |
| Шифртекст | Зашифрованные данные |
| AAD (контекст) | Связанные данные шифрования, привязывающие шифртекст к сейфу, записи и версии ключа |
| k-anonymity | Способ проверки утечек без передачи пароля целиком |
| SBOM | Состав зависимостей выпуска (CycloneDX, SPDX) |
