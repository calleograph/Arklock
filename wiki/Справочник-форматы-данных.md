# Справочник: форматы данных

> Относится к версии 1.86.0 · проверено 2026-10-28 · уровень проверки 2 (источник: `docs/security/export-format.md`, `packages/crypto`, тесты `services.test.ts`)

*Тип страницы: справочник.*

## Зашифрованный архив экспорта

Создаётся в браузере («Импорт и экспорт → Экспорт → Зашифрованный архив»). Сервер видит только факт выгрузки (формат и число записей).

### Защита

| Что | Значение |
| --- | --- |
| Пароль | 30 случайных знаков (буквы двух регистров, цифры, спецсимволы; без похожих знаков, кавычек, пробелов и обратной косой); `crypto.getRandomValues` |
| Вывод ключа | Argon2id: 64 МиБ, 3 прохода, 1 поток. Пароль нормализуется NFKC. Соль — 16 случайных байт; в Argon2id используется соль ‖ `arklock-export`. Затем HKDF-SHA-256 (метка `arklock/v1/wrap`) |
| Шифрование | AES-256-GCM, случайный 96-битный nonce, тег 128 бит, связанные данные `arklock-export-v1` |
| Нижняя граница | Параметры Argon2id ниже 19 МиБ и 2 проходов при открытии отклоняются |

### Структура файла

```json
{
  "format": "arklock-encrypted",
  "version": 1,
  "kdf": { "memoryKiB": 65536, "iterations": 3, "parallelism": 1 },
  "salt": "<16 байт, base64url>",
  "data": "ak1.<nonce, base64url>.<шифртекст с тегом, base64url>"
}
```

Расшифрованное содержимое — JSON `arklock-export` версии 2: `{ "format", "version": 2, "exportedAt", "vaults": [ { "name", "branches": [ { "id", "parentId", "name", "icon" } ], "entries": [ { …поля записи, "branchId", "attachments": [ { "name", "type", "data" } ] } ] } ] }`. Версия 1 (выгрузка одного сейфа) читается.

Поля записи: вид, название, логин, пароль, адрес, заметки, TOTP, дополнительные поля, метки, срок действия, связи, значок. Вложения — Base64 внутри записи.

### Расшифровка вне Arklock

1. Прочитайте `kdf` и `salt`. Соль Argon2id = `salt` ‖ UTF-8 `arklock-export`.
2. Argon2id(пароль NFKC, соль, m, t, p) → 32 байта.
3. HKDF-SHA-256 (материал — результат шага 2, соль — `salt`, info — `arklock/v1/wrap`) → 32 байта ключа.
4. Разделите `data` по точке: `ak1`, nonce, шифртекст. Расшифруйте AES-256-GCM со связанными данными `arklock-export-v1`.
5. Результат — UTF-8 JSON.

## Открытые форматы экспорта

JSON и CSV не зашифрованы: пароли в открытом виде. CSV хранит название, логин, пароль, адрес, заметки, TOTP, папку и метки; дополнительные поля и вложения в нём не сохраняются.

## Форматы импорта

CSV, Bitwarden JSON, Passwork JSON, KeePass XML (KeePass 2), JSON Arklock, зашифрованный архив Arklock. Таблица возможностей — на странице [Как импортировать и экспортировать](Как-импортировать-и-экспортировать-пароли).

## Формат шифртекста в базе

| Значение | Формат |
| --- | --- |
| Шифртекст | `ak1.<nonce b64url>.<ciphertext‖tag b64url>` |
| Запечатанное значение | `as1.<эфемерный открытый ключ b64url>.<ak1…>` |

Префикс — версия формата. Контекст шифрования (AAD) имеет вид `тип|["часть1","часть2",…]`; части кодируются JSON-массивом, поэтому границы однозначны.
