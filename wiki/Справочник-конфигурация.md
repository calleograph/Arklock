# Справочник: конфигурация

> Относится к версии 1.79.0 · проверено 2026-10-27 · уровень проверки 1 (источники: `apps/api/src/config.ts`, `compose.yaml`, `install.sh`)

*Тип страницы: справочник.*

Основная конфигурация лежит в `/etc/arklock/arklock.env` (права 600, читает только root). Значения не показывайте в обращениях и публикациях.

## Переменные процесса приложения

Приложение проверяет значения при запуске; неверная конфигурация — отказ запуска с понятной ошибкой.

| Переменная | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `NODE_ENV` | `development` / `test` / `production` | `production` | Режим |
| `HOST` | строка | `0.0.0.0` | Адрес прослушивания внутри контейнера |
| `PORT` | 1–65535 | `8080` | Порт внутри контейнера |
| `LOG_LEVEL` | `fatal`, `error`, `warn`, `info`, `debug`, `trace`, `silent` | `info` | Уровень журнала |
| `DATABASE_URL` | строка | обязательна | `postgres://…`; `pglite:<каталог>` или `pglite:memory` — для разработки и тестов |
| `APP_SECRET` | строка ≥ 32 символов | обязательна | Секрет приложения. Запечатывает настройки сервера (LDAP, SMTP, SAML) и даёт правдоподобные ответы для неизвестных адресов. **Не ключ шифрования данных** |
| `BOOTSTRAP_TOKEN` | строка ≥ 24 символов | не задан | Одноразовый код создания первого администратора |
| `UPDATER_DIR` | путь | пусто | Каталог обмена с помощником обновлений; пусто — раздел обновлений недоступен |
| `BLOB_DIR` | путь | пусто | Каталог зашифрованных вложений; пусто — вложения недоступны |
| `APP_PUBLIC_URL` | URL | не задан | Публичный адрес; значение в панели главнее |
| `APP_BIND` | строка ≤ 100 | не задан | Адрес публикации на хосте (только показ в панели) |
| `APP_HOST_PORT` | целое | не задан | Порт публикации на хосте (только показ в панели) |
| `WEB_DIST` | путь | пусто | Каталог веб-клиента |
| `TRUSTED_PROXY_HOPS` | 0–5 | `1` | Число прокси перед приложением; `0` — заголовок `X-Forwarded-For` игнорируется. Список адресов прокси в панели главнее числа |
| `SESSION_IDLE_HOURS` | число > 0 | `12` | Простой до окончания сеанса |
| `SESSION_MAX_DAYS` | число > 0 | `7` | Предельная длительность сеанса |
| `LOGIN_MAX_ATTEMPTS` | целое ≥ 1 | `10` | Попыток входа в окне |
| `LOGIN_WINDOW_MINUTES` | число > 0 | `15` | Окно ограничения попыток |
| `APP_VERSION`, `APP_GIT_COMMIT`, `APP_BUILT_AT` | строка | `0.0.0`, `unknown`, `unknown` | Задаются при сборке образа |
| `UPDATE_CHANNEL` | `stable` / `edge` | `stable` | Канал обновлений |
| `AUTO_UPDATE` | `on` / `off` | `on` | Планировщик автоматических проверок и установки; `off` — для стендов |

## Переменные файла `arklock.env`, которые использует Compose

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `COMPOSE_PROJECT_NAME` | `arklock` | Имя проекта Compose |
| `POSTGRES_PASSWORD` | обязательна | Пароль PostgreSQL (создаётся установщиком) |
| `ARKLOCK_IMAGE` | `<проект>-app:local` (установщик) | Образ приложения |
| `INSTALL_PROFILE` | `standalone` или `shared-host` | Профиль установки |
| `INSTALL_DIR` | `/opt/arklock` | Каталог программы |
| `APP_BIND` | выбор установщика (`127.0.0.1` в варианте `local`) | Адрес публикации порта |
| `APP_PORT` | `8080` | Порт публикации на хосте |
| `DATA_ROOT` | `/var/lib/arklock` | Каталог данных: `updater`, `blobs`, `backups`, `logs` |
| `BACKUP_KEY_FILE` | `/etc/arklock/backup.key` | Ключ резервного шифрования |

Контейнер приложения работает с `read_only`, `cap_drop: ALL` и `no-new-privileges`; база находится во внутренней сети.

## Параметры безопасности по умолчанию

| Параметр | Значение |
| --- | --- |
| Argon2id | m=64 МиБ, t=3, p=1; нижняя граница сервера m=19 МиБ, t=2 |
| Сеанс | простой 12 ч, предел 7 суток |
| Токен сеанса | `aks_…`, токен API `akt_…`; хранится SHA-256 |
| Проверка новой версии | каждые 30 минут |
| Плановая сверка LDAP | каждые 30 минут, если включена в подключении |
| Метрики серверных ресурсов | выборка каждые 5 минут, хранение 14 суток |

## Настройки в панели

Остальные настройки (почта, политики паролей, личные сейфы, срок хранения журнала, PIN и разблокировка после F5) хранятся в базе и меняются в «Администрирование». Они входят в резервную копию.
