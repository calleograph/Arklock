# Как работать из командной строки

> Относится к версии 1.78.0 · проверено 2026-10-27 · уровень проверки 2 (`tokens.test.ts`, тесты клиента). Команды этой страницы автором вики не запускались.

*Тип страницы: практическое руководство.*

Для кого: администратор и разработчик. Результат: чтение и создание записей без браузера. Нужно заранее: Node.js 24, сборка из репозитория, токен API.

Клиент `arklock` работает на вашем компьютере. Пароль разблокировки сейфов превращается в ключи локально; серверу уходят токен и шифртекст. **Токен API не открывает данные**: у него нет ключей.

## Создать токен

В веб-интерфейсе «Безопасность → Токены API и командная строка». Нужны пароль разблокировки сейфов и код второго фактора (если включён). Токен показывается один раз; сервер хранит только его SHA-256.

- **Только чтение** — разрешены GET-запросы.
- **Чтение и запись** — разрешены изменения в хранилищах.
- Срок в днях (0 — без срока), отзыв в любой момент.
- Токену недоступны управление учётной записью, сеансы, второй фактор, другие токены и административные маршруты (ответ 403 `token_not_allowed`).

## Установить и настроить

```bash
npm ci && npm run build
node apps/cli/dist/main.js help
node apps/cli/dist/main.js config --server https://arklock.example.com --token YOUR_TOKEN
```

Файл настроек: `~/.config/arklock/config.json` (права 600; каталог переопределяет `ARKLOCK_CONFIG_DIR`).

## Команды

| Команда | Что делает |
| --- | --- |
| `arklock config --server URL --token YOUR_TOKEN` | сохранить адрес и токен |
| `arklock login --server URL --email ACCOUNT` | войти по имени или почте и коду второго фактора |
| `arklock whoami`, `arklock vaults` | кто вошёл, какие сейфы доступны |
| `arklock list [-q текст] [--vault имя] [--json]` | список записей |
| `arklock get <запись> [--field password\|username\|url\|notes\|totp\|имя] [--json]` | прочитать запись или поле |
| `arklock totp <запись>` | текущий код TOTP |
| `arklock add --title T [--username U] [--password P \| --generate] [--folder A/B]` | создать запись (нужен токен с записью) |
| `arklock generate [--length N] [--phrase]` | пароль или парольная фраза |

Пароль разблокировки сейфов берётся из `ARKLOCK_PASSWORD` или запрашивается в терминале. Адрес и токен можно задать `ARKLOCK_SERVER` и `ARKLOCK_TOKEN`; код второго фактора — `ARKLOCK_MFA_CODE`.

> **Предупреждение.** Не храните `ARKLOCK_PASSWORD` в истории оболочки и в общих скриптах.

## Защита

Подписи выданных ключей проверяются по журналу ключей. Клиент запоминает последнее состояние журнала и отказывается работать, если оно изменилось задним числом.
