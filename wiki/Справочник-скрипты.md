# Справочник: скрипты сервера

> Относится к версии 1.86.1 · проверено 2026-10-28 · уровень проверки 1 (чтение `install.sh` и `scripts/*.sh`; сценарии установки, копий и обновления проверяются в CI, остальные команды автором не запускались)

*Тип страницы: справочник.*

Скрипты находятся в `/opt/arklock/scripts` (каталог программы). Все запускаются от root.

## Установка и сеть

| Команда | Назначение |
| --- | --- |
| `install.sh [параметры]` | Установка и повторный запуск |
| `scripts/proxy.sh setup\|status\|renew\|remove\|print` | Nginx и HTTPS |
| `scripts/access.sh status\|check\|proxy-help\|set local\|proxy\|https` | Способ доступа и готовность первого входа: что настроено, проверки публичного адреса и прокси, смена без переустановки (данные не затрагиваются, копия настроек сохраняется) |
| `scripts/preflight.sh` | Проверка требований перед установкой или обновлением |

### Параметры `install.sh`

| Параметр | Значение |
| --- | --- |
| `--profile` | `standalone` или `shared-host` |
| `--dir`, `--data`, `--config`, `--project` | каталог программы (`/opt/arklock`), данных (`/var/lib/arklock`), настроек (`/etc/arklock`), имя проекта (`arklock`) |
| `--port` | порт публикации (с 8080; занятый — отказ) |
| `--bind` | `local`, `lan`, `all` или адрес |
| `--url` | публичный адрес (`https://…`) |
| `--https`, `--domain`, `--email`, `--tls-cert`, `--tls-key` | автоматическая настройка Nginx: `letsencrypt`, `self-signed`, `existing` |
| `--ref` | версия (тег); `main` — только с `--allow-unreleased` |
| `--repo`, `--allow-unreleased`, `--yes`, `--dry-run` | источник кода, непомеченная ветка, без вопросов, пробный прогон |

Переменные окружения: `ARKLOCK_ALLOW_UNSUPPORTED_OS=1` (неподдерживаемая ОС), `ARKLOCK_PULL_RELEASE_IMAGE=0` (не скачивать образ), `ARKLOCK_PROXY_FORCE=1` (настройка прокси при чужих сайтах).

## Состояние и диагностика

| Команда | Назначение |
| --- | --- |
| `scripts/status.sh` | версии, контейнеры, место, последние копии |
| `scripts/verify.sh` | контейнеры и healthcheck, API, версия, схема БД, права файлов, непубликуемость БД, работа без root, место (код 1 при ошибках) |
| `scripts/smoke-test.sh` | быстрые проверки сценариев без изменения данных |
| `scripts/logs.sh` | журналы контейнеров с маскированием токенов и паролей |
| `scripts/diag.sh` | диагностический пакет без паролей и ключей |
| `scripts/repair.sh [--restart]` | безопасные исправления: каталоги, права, проверка БД; перезапуск — только с `--restart`. Не очищает БД, не удаляет тома, не пересоздаёт секреты |

## Копии

| Команда | Назначение |
| --- | --- |
| `scripts/backup.sh [--keep N] [--label имя]` | создать копию |
| `scripts/backup.sh --verify ФАЙЛ` | проверить копию |
| `scripts/backup.sh --restore-test ФАЙЛ` | пробное восстановление во временную базу |
| `scripts/restore.sh ФАЙЛ [--yes]` / `--remote ИМЯ` | восстановить |
| `scripts/remote.sh configure\|test\|list\|verify ИМЯ\|pull ИМЯ [КАТАЛОГ]\|push ФАЙЛ\|prune N\|delete ИМЯ\|clear` | удалённое хранилище (S3, SMB) |

## Обновления

| Команда | Назначение |
| --- | --- |
| `scripts/check-updates.sh` | код 10 — есть новая версия, 1 — репозиторий недоступен |
| `scripts/update.sh [--ref vX.Y.Z] [--yes]` | обновить |
| `scripts/rollback.sh [--with-restore]` | откатить; код 3 — схема изменилась |
| `scripts/updater.sh status\|repair\|uninstall` | служба помощника обновлений |

## Администрирование без веб-интерфейса

`scripts/admin-reset.sh` возвращает административный доступ оператору сервера. Каждое действие пишется в журнал от имени `operator`. Скрипт не сбрасывает пароль разблокировки сейфов и не читает данные.

| Команда | Действие |
| --- | --- |
| `list` | администраторы, кто главный, включены ли, есть ли второй фактор |
| `reset-mfa ПОЧТА` | снять второй фактор |
| `end-sessions ПОЧТА` | завершить сеансы |
| `enable ПОЧТА` | включить отключённую учётную запись |
| `promote ПОЧТА` | сделать администратором |
| `chief ПОЧТА` | назначить главного администратора, если прежний недоступен |
| `new-setup-token` | новый код первой настройки (пока нет пользователей) |

Параметры: `--env ФАЙЛ`, `--yes`.
