# О продукте

> Относится к версии 1.84.0 · проверено 2026-10-28 · уровень проверки 1

*Тип страницы: объяснение.*

## Какую задачу решает Arklock

Пароли компании часто хранятся в чатах и таблицах. Когда сотрудник уходит, никто не знает, к чему он имел доступ. Новому сотруднику собирают доступы вручную.

Arklock — общее хранилище паролей для команды на вашем сервере. Оно выдаёт доступ людям и группам, показывает, кто что видит, и при увольнении закрывает доступ и перечисляет пароли, которые нужно сменить.

## Для кого

- Организации от 5 до нескольких сотен человек, которым нужен собственный менеджер паролей.
- ИТ-отделы и команды разработки, которым нужны общие секреты с разграничением доступа.
- Организации с Active Directory или LDAP: сотрудники входят с учётной записью каталога.

## Что отличает Arklock

- **Шифрование в браузере.** Сервер получает только шифртекст. Администратор сервера не может прочитать записи ([механизм](Безопасность-и-приватность)).
- **Самостоятельное размещение.** Данные остаются на вашем сервере. Облачного сервиса нет.
- **Администрирование из браузера.** Обновления, копии, почта и сертификаты настраиваются в панели ([Как обновить](Как-обновить-и-откатить)).
- **Без платных ограничений.** Нет редакций, лицензионных ключей и телеметрии ([Лицензия](Лицензия-и-политика-безопасности)).

## Когда Arklock не подходит

| Ситуация | Причина |
| --- | --- |
| Нужен сервис «как в облаке» без своего сервера | Arklock устанавливается и обслуживается вами |
| Нужен независимо проверенный продукт | Криптография не проходила независимый аудит ([материалы для аудита](Безопасность-и-приватность)) |
| Нужны нативные приложения для iOS и Android | Есть PWA и расширения браузера, нативных приложений нет |
| Нужна криптографическая изоляция одной записи внутри сейфа | Участник с ключом сейфа технически может расшифровать любую запись сейфа; для разных границ доверия используйте разные сейфы |
| Нужно автоматическое создание учётных записей из каталога (SCIM) | SCIM не реализован |
| Нужны несколько хранилищ для вложений | Вложения лежат в одном каталоге сервера |
| Закрытый контур без интернета | Офлайн-установка не реализована ([Установка](Установка)) |
