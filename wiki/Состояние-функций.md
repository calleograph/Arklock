# Состояние функций

> Относится к версии 1.82.0 · проверено 2026-10-28 · уровень проверки 2

*Тип страницы: справочник.*

Источник сведений — [docs/FEATURE_STATUS.md](https://github.com/calleograph/Arklock/blob/main/docs/FEATURE_STATUS.md) в репозитории; страница ниже сводит его к статусам и уровням проверки.

## Статусы

| Статус | Значение |
| --- | --- |
| Реализовано и проверено | Есть код и автоматические тесты |
| Частично | Работает не полностью; граница указана |
| Не реализовано | В продукте нет |
| Архитектурное ограничение | Следует из модели шифрования |

## Уровни проверки

| Уровень | Значение |
| --- | --- |
| 0 | Заявлено в документах |
| 1 | Подтверждено чтением кода |
| 2 | Подтверждено автоматическими тестами (модульные, API, браузерные сценарии в CI) |
| 3 | Подтверждено запуском в среде автора |
| 4 | Подтверждено в реальной инфраструктуре заказчика |

Ни одна интеграция с внешней инфраструктурой (Active Directory, SSO, SAML, SMB, S3, почта) не подтверждена уровнем 4. Для них указана граница проверки.
