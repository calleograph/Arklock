# Системные требования

> Относится к версии 1.85.0 · проверено 2026-10-28 · уровень проверки 2

*Тип страницы: справочник.*

## Сервер

| Параметр | Требование |
| --- | --- |
| Операционная система | Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, Debian 12 |
| Архитектура | x86_64 или aarch64 |
| Права | root |
| Память | от 1 ГБ |
| Место | от 3 ГиБ в каталоге данных (по умолчанию `/var/lib/arklock`) |
| Сеть | Доступ в интернет для пакетов, Docker и загрузки выпуска |
| Docker | Engine с Compose Plugin; в профиле `standalone` установщик ставит его сам |

В CI проверена только Ubuntu 24.04. Ubuntu 22.04 и Debian 12 заявлены, но автоматически не проверялись. На другой системе установку можно запустить с `ARKLOCK_ALLOW_UNSUPPORTED_OS=1` без гарантий.

Место для обновления считается по фактическим размерам: образ ×2, база ×2, вложения ×2 и запас. При нехватке обновление не начинается ([Как обновить и откатить](Как-обновить-и-откатить)).

## Компоненты, которые ставит установщик

- PostgreSQL 16 (образ `postgres:16-alpine`) и приложение — отдельным проектом Docker Compose.
- Помощник обновлений — служба systemd `arklock-updater-<проект>`.

Установщик не трогает чужие контейнеры, чужие порты и Nginx других сайтов в профиле `shared-host`.

## Клиент

| Клиент | Требование |
| --- | --- |
| Браузер | Современный браузер с WebCrypto и защищённым контекстом (HTTPS или `localhost`). Автоматические сценарии выполняются в Chromium; Firefox и Safari для веб-клиента автоматически не проверялись |
| Расширение | Chromium (Chrome, Edge, Brave); Firefox 140 и новее |
| Телефон | Установка PWA через браузер |
| Командная строка | Node.js 24 и сборка из репозитория |

Без HTTPS вход, регистрация и разблокировка не работают: браузер не даёт выполнить шифрование ([Как настроить HTTPS](Как-настроить-HTTPS-и-reverse-proxy)).
