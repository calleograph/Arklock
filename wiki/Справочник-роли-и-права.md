# Справочник: роли и права

> Относится к версии 1.81.0 · проверено 2026-10-28 · уровень проверки 2 (источник: `apps/api/src/perms.ts`; тесты `roles.test.ts`, `object-access.test.ts`, `chief.test.ts`, `departments.test.ts`)

*Тип страницы: справочник.*

Все проверки выполняются на сервере по эффективному набору полномочий. Интерфейс лишь скрывает недоступное.

## Правила вычисления

- Эффективные полномочия = объединение разрешений роли и её родителей минус объединение запретов. Запрет сильнее разрешения.
- Права на сейф, группы, папки-предки и запись объединяются по наибольшему уровню; явный «Нет доступа» сильнее любого разрешения.
- Истёкшие назначения не учитываются.
- Нельзя назначить роль с полномочиями, которых нет у назначающего.
- Роль, которая назначена или унаследована другой ролью, удалить нельзя.

## Полномочия сейфа

| Полномочие | Что разрешает |
| --- | --- |
| `entry.read` | читать записи |
| `entry.history` | читать историю версий |
| `entry.create`, `entry.update`, `entry.delete` | создавать, изменять, удалять записи |
| `attachment.read`, `attachment.write` | читать и загружать вложения |
| `branch.manage` | управлять папками |
| `trash.purge` | удалять из корзины навсегда |
| `grant.manage` | управлять доступом к объектам |
| `members.manage` | управлять участниками сейфа |
| `vault.settings` | менять настройки сейфа |
| `vault.rotate` | менять ключ сейфа |
| `vault.delete` | удалять сейф |
| `vault.signals` | видеть события безопасности сейфа |

## Встроенные роли сейфа

| Роль | Состав |
| --- | --- |
| Читатель (`reader`) | `entry.read`, `entry.history`, `attachment.read`, `vault.signals` |
| Редактор (`editor`) | читатель + `entry.create/update/delete`, `attachment.write`, `branch.manage`, `trash.purge` |
| Администратор сейфа (`admin`) | редактор + `grant.manage`, `members.manage`, `vault.settings`, `vault.rotate` |
| Владелец (`owner`) | администратор + `vault.delete` |
| Ограниченный (`limited`) | нет полномочий |

Встроенные роли не изменяются. Пользовательские роли создаются в «Администрирование → Безопасность → Роли».

## Уровни доступа к папкам и записям

Правила объекта задаются во вкладке «Доступ». Уровни повышают права наследуемым правилом, но не понижают. Для папок есть уровень **«Структура»**: видеть папку и вложенные, создавать записи и подпапки, не читая записей. Запрет не даёт криптографической изоляции ([Как работает отзыв доступа](Как-работает-отзыв-доступа)).

## Административные полномочия

| Полномочие | Раздел панели |
| --- | --- |
| `admin.users` | пользователи |
| `admin.circles` | группы |
| `admin.settings` | настройки |
| `admin.ledger` | журнал действий |
| `admin.system` | система |
| `admin.backups` | резервные копии |
| `admin.updates` | обновления |
| `admin.integrations` | интеграции |
| `admin.invitations` | приглашения |
| `admin.roles` | роли |

Административная роль назначается пользователю или группе, в том числе сопоставленной с группой AD/LDAP. Итог — объединение ролей пользователя и его групп; исключение из группы действует сразу. Роль не открывает содержимое сейфов. Состав группы с административной ролью и саму роль меняет только полный администратор. Назначение административной роли завершает сеансы пользователя.

## Типы администраторов

| Тип | Признак | Возможности |
| --- | --- | --- |
| Главный администратор | `chief` | назначает и снимает полных администраторов, импорт и экспорт, обзор организации, инвентаризация сейфов, передача роли и добавление ещё одного главного |
| Полный администратор | `role = admin` | все разделы панели; передача владения при увольнении; корпоративное восстановление |
| Делегированный администратор | административная роль | только разрешённые разделы; не создаёт роли выше своих и не трогает полных администраторов |
| Администратор пространства | роль «администратор пространства» | управляет составом и сейфами своего пространства |
| Сотрудник | — | работает с доступными сейфами |

Главных администраторов может быть несколько. Последнего действующего главного отозвать нельзя, главного нельзя понизить, отключить или уволить, пока у него есть эта роль. Предложение роли преемник принимает своим паролем разблокировки сейфов в течение 72 часов.

## Подразделения

Закрытое пространство подразделения не раскрывает метаданные другим подразделениям ни в списках, ни по прямой ссылке (проверено `departments.test.ts`, 20 маршрутов). Справочник людей и групп общий для организации.
