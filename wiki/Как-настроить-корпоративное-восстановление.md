# Как настроить корпоративное восстановление

> Относится к версии 1.77.0 · проверено 2026-10-27 · уровень проверки 2. **Статус функции: частично реализовано.** Независимая проверка механизма не проводилась.

*Тип страницы: практическое руководство.*

Для кого: полный администратор. Результат: на случай потери ключей участников организация может вернуть владение заранее подключёнными сейфами. Нужно заранее: безопасное место для файла и парольной фразы вне Arklock.

Механизм не восстанавливает шифртексты, для которых ключ никогда не был подключён. При потере одновременно ключей участников и офлайн-пакета с фразой расшифровка невозможна. Сервер мастер-ключа не имеет.

## Подготовка

1. Откройте «Настройки → Безопасность → Корпоративное восстановление».
2. Создайте пакет с парольной фразой от 20 символов.
3. Скачайте зашифрованный JSON, сохраните файл и фразу **отдельно, вне Arklock**, и подтвердите сохранение. Только после этого активируется публичный получатель.

## Подключить сейфы

Само включение функции не открывает корпоративные секреты. Для каждого корпоративного сейфа участник с текущим ключом открывает настройки сейфа, сверяет отпечаток и подключает сейф. Сервер получает только подписанный зашифрованный пакет ключа.

Ротация ключа подключённого сейфа обязана одновременно обновить пакет восстановления; иначе сервер отвергает операцию.

## Восстановить доступ при аварии

1. Полный администратор импортирует офлайн-файл и фразу в браузере. Закрытые ключи не отправляются серверу.
2. Одноразовый запрос привязан к администратору, сеансу, сейфу и версии ключа, действует 5 минут и требует владения обоими ключами пакета.
3. Подтверждённое восстановление выдаёт ключ текущей учётной записи и делает её владельцем сейфа. В закрытом пространстве администратор становится участником. Прежний владелец сохраняет роль администратора. Действие записывается в журнал.

## Заменить пакет

Если пакет или фраза утрачены или скомпрометированы: «Настройки → Безопасность → Замена офлайн-пакета». Создайте и сохраните новый пакет, подключите к нему каждый защищённый сейф. Пока не подключены все, замену не завершить. После завершения старый пакет перестаёт работать. Замену можно отменить; прежний пакет остаётся. Одновременно готовится только одна замена.

## Ограничения

- Получатель один.
- Работает только для заранее подключённых сейфов с актуальным пакетом.
- Роль главного администратора с получателем не связана.
