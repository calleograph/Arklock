# Как пользоваться расширением и телефоном

> Относится к версии 1.86.1 · проверено 2026-10-28 · уровень проверки 2 для Chromium (`e2e/extension.spec.ts`); Firefox — частично (см. ниже); Firefox для Android не проверялся

*Тип страницы: практическое руководство.*

Для кого: сотрудник и администратор. Результат: расширение заполняет формы входа, а Arklock установлен на телефоне как приложение.

## Расширение браузера

В магазинах расширений Arklock **не опубликован**, нужна сборка из исходников.

### Установить в Chromium (Chrome, Edge, Brave)

1. Соберите проект:

   ```bash
   npm ci && npm run build
   ```

   Результат: каталог `apps/extension/dist`.
2. Откройте страницу расширений, включите режим разработчика, нажмите «Загрузить распакованное» и выберите `apps/extension/dist`.

### Установить в Firefox

Сборка создаёт `apps/extension/dist-firefox`. Временная установка: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `manifest.json` из каталога. Постоянная установка требует подписи Mozilla. Идентификатор по умолчанию `arklock@example.com` — для распространения задайте свой через `EXT_GECKO_ID`.

### Войти

- По почте и паролю разблокировки сейфов (и коду второго фактора, если он включён).
- По токену API и паролю разблокировки сейфов — для учётных записей, входящих через SSO или каталог. Токен создаётся в «Безопасность → Токены API».

Браузер запросит доступ только к адресу вашего сервера. `http://` допустим только для `localhost`.

### Заполнить форму

Нажмите «Заполнить» на вкладке. Расширение не внедряет скрипты само. Запись предлагается, если узел совпадает (без `www`) или страница — поддомен узла записи. Для несовпавшего узла и понижения https до http запрашивается подтверждение.

Можно создавать и изменять записи, копировать, смотреть TOTP и пользоваться генератором. При конфликте версий расширение сообщает об этом и ничего не затирает.

### Что где хранится

Сессия и ключи — в `chrome.storage.session` (память браузера, на диск не пишется). Автоблокировка: 5 минут по умолчанию. В `chrome.storage.local` лежат только адрес сервера, почта и время автоблокировки.

### Что не проверено и не реализовано

В Firefox автоматически проверяются манифест и загрузка расширения, но не сценарии входа и заполнения: WebDriver не управляет такими страницами. Эти сценарии выполняются на том же коде в Chromium. Не реализованы автоматическое предложение сохранить пароль, заполнение по горячей клавише и публикация в магазинах.

## Телефон

Нативных приложений для iOS и Android нет. Установите веб-приложение (PWA): Chrome, Edge, Android — «Установить приложение»; iOS Safari — «На экран “Домой”». Приложение открывается в отдельном окне. Service worker кэширует только статические файлы интерфейса; запросы `/api/` не кэшируются. Без сети данные недоступны.

Интерфейс проверяется на ширине 390 px без горизонтальной прокрутки.

## Типичные ошибки

- Расширение не видит запись: проверьте адрес записи и узел страницы.
- Доступ к хранилищу пропал после «Обновить»: вам отозвали доступ или завершили сеанс; войдите заново.
