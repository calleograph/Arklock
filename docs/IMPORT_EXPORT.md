# Импорт и экспорт

Раздел открывается из главного меню (**Импорт и экспорт**) и из левого меню администрирования (группа «Данные»). Всё происходит в браузере: файл не уходит на сервер, пока вы не сохраните записи в сейф.

## Импорт

1. Выберите **пространство** и **сейф**, куда добавить записи (доступны только сейфы, где вам разрешено создавать записи).
2. Выберите файл. Формат определяется сам, его можно сменить вручную:
   - **CSV**;
   - **Bitwarden JSON**;
   - **Passwork JSON**;
   - **KeePass XML** (KeePass 2);
   - **JSON Arklock** (в том числе выгрузка нескольких сейфов);
   - **зашифрованный архив Arklock** — потребуется пароль архива.
3. Для CSV отметка **«Пропустить первую строку (заголовки)»** ставится автоматически, если в первой строке названия столбцов; её можно снять. Каждый столбец сопоставляется с полем записи в выпадающем списке над таблицей; пароли в предпросмотре скрыты.
4. Предпросмотр показывает число записей, дубликатов, вложений и замечания по строкам. Дубликатом считается запись с тем же названием, логином и адресом: уже есть в сейфе или повторяется в файле. По умолчанию они пропускаются.
5. **Импортировать**: появится индикатор выполнения, затем итог (создано, пропущено, ошибок).

Существующие записи **не изменяются и не перезаписываются**: импорт только добавляет новые. Папки создаются по пути из файла (до любой вложенности), значки папок из выгрузки Arklock восстанавливаются. Выгрузка нескольких сейфов раскладывается по папкам с названиями исходных сейфов.

Что сохраняется по форматам:

| Формат | Папки | TOTP | Доп. поля | Вложения |
| --- | --- | --- | --- | --- |
| JSON Arklock и архив | да, с вложенностью и значками | да | да | да |
| Bitwarden JSON | да (вложенность через «/» в названии папки) | да | да | нет |
| Passwork JSON | да (цепочка папок) | да | да | нет |
| KeePass XML | да (группы) | как дополнительное поле | да | нет |
| CSV | по столбцу «Папка» (`А/Б/В`) | по столбцу | нет | нет |

## Экспорт

1. Выберите область: **один сейф**, **все сейфы пространства** или **все доступные сейфы** (включая личный, если он разрешён организацией).
2. Выберите формат:
   - **Зашифрованный архив** (рекомендуется). Пароль создаётся автоматически: 30 случайных знаков. Он показан перед выгрузкой; рядом кнопки **«Копировать»** и **«Создать новый»**. Сохраните его отдельно от файла. Восстановить пароль нельзя. Описание формата: [security/export-format.md](security/export-format.md).
   - **JSON** — открытый текст, сохраняет всё содержимое записей и вложения.
   - **CSV** — открытый текст, для таблиц и других программ; только основные поля.
3. Для открытых форматов нужна отметка о понимании риска: файл не зашифрован.
4. **Выгрузить**. Вложения включаются отметкой (до 20 МБ каждое и до 128 МБ в сумме; остальные пропускаются, о числе пропущенных сообщается).

Выгружается только то, что вам разрешено читать, и только из сейфов, ключ которых выдан вам. Роль главного администратора здесь ничего не расширяет: чужие личные сейфы и сейфы без выданного ключа недоступны (см. [корпоративный доступ](administration/corporate-access.md)). Сейфы без доступа перечислены числом в подсказке над кнопкой.

В журнал действий записываются формат и число записей, но не пароль архива и не содержимое.

## Если что-то пошло не так

| Сообщение | Что делать |
| --- | --- |
| «Неверный пароль архива или повреждённый файл» | Проверьте пароль (регистр, лишние пробелы при копировании). Если пароль верный, файл изменён или повреждён: возьмите исходную копию. |
| «Файл больше 200 МБ» | Разделите выгрузку по сейфам. |
| «У вас нет права добавлять записи ни в один сейф» | Попросите владельца сейфа выдать роль не ниже «Редактор». |
| Дубликаты пропущены, а нужны | Снимите отметку «Пропускать дубликаты». |

В Bitwarden JSON переносятся логины и защищённые заметки; карточки и удостоверения как записи не создаются полноценно (только название). Зашифрованная выгрузка Bitwarden не читается: выгрузите данные без шифрования, импортируйте и удалите файл.
