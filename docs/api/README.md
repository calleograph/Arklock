# API v1

Базовый путь: `/api/v1`. Формат — JSON. Ошибки: `{ "error": { "code", "message", "requestId", "details?" } }`. Сообщения не содержат секретов и не повторяют присланные значения. Схемы запросов и ответов — `packages/contracts`.

Аутентификация: заголовок `Authorization: Bearer aks_…` (токен выдаётся при входе; сервер хранит только его SHA-256).

## Система

| Метод | Путь     | Описание                                  |
| ----- | -------- | ----------------------------------------- |
| GET   | /health  | процесс жив                               |
| GET   | /ready   | готовность (доступность БД), 503 при сбое |
| GET   | /version | версия, сборка, канал обновлений          |

## Учётные записи и сессии

| Метод  | Путь                       | Доступ     | Описание                                                                                        |
| ------ | -------------------------- | ---------- | ----------------------------------------------------------------------------------------------- |
| GET    | /auth/registration         | публичный  | можно ли создать учётную запись                                                                 |
| GET    | /auth/params?email=        | публичный  | идентификатор, соль и параметры Argon2id (для неизвестных адресов — правдоподобные значения)   |
| POST   | /auth/register             | публичный  | регистрация: ключи создаются клиентом; первая запись — администратор; далее по настройке        |
| POST   | /auth/login                | публичный  | вход по `authKey`; ограничение попыток; ответ — токен и ключи пользователя (в зашифрованном виде) |
| POST   | /auth/logout               | сессия     | завершить текущий сеанс                                                                         |
| GET    | /auth/me                   | сессия     | текущий пользователь                                                                            |
| GET    | /auth/sessions             | сессия     | активные сеансы                                                                                 |
| DELETE | /auth/sessions/:id         | сессия     | завершить свой сеанс                                                                            |
| POST   | /auth/sessions/revoke-others | сессия   | завершить все остальные                                                                         |
| POST   | /auth/change-password      | сессия     | смена мастер-пароля (перешифровывается только закрытый ключ аккаунта); остальные сеансы завершаются |
| POST   | /auth/recovery/start       | публичный  | шаг 1 восстановления: зашифрованный ключом восстановления закрытый ключ                         |
| POST   | /auth/recovery/complete    | публичный  | шаг 2: доказательство владения ключом восстановления, новый пароль, новый ключ восстановления   |

## Хранилища и записи

Не участнику хранилище неотличимо от несуществующего (404). Запись — только шифртекст.

| Метод  | Путь                              | Описание                                                                            |
| ------ | --------------------------------- | ----------------------------------------------------------------------------------- |
| GET    | /vaults                           | хранилища пользователя с запечатанным для него ключом                               |
| GET    | /vaults/:vaultId/entries          | записи хранилища                                                                    |
| POST   | /vaults/:vaultId/entries          | создать (`id` задаёт клиент — он входит в контекст шифрования)                      |
| GET    | /vaults/:vaultId/entries/:entryId | получить                                                                            |
| PUT    | /vaults/:vaultId/entries/:entryId | изменить; `expectedVersion` обязателен, при расхождении — 409 `version_conflict`   |
| DELETE | /vaults/:vaultId/entries/:entryId?expectedVersion= | удалить в корзину (мягкое удаление)                                |

Коды: 400 `validation_error`/`weak_kdf`, 401 `unauthorized`/`invalid_credentials`, 403 `forbidden`/`registration_closed`, 404 `not_found`, 409 `already_exists`/`version_conflict`/`stale_key_version`, 429 `too_many_attempts` (заголовок `Retry-After`).
