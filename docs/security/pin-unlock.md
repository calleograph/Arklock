# Быстрая разблокировка PIN-кодом

Выключена по умолчанию. Администратор включает её в Администрирование → Настройки → Безопасность. Сотрудник включает PIN на конкретном устройстве в Настройках (нужен пароль разблокировки сейфов; PIN — 6–12 цифр).

## Что это даёт и чего не даёт

- PIN заменяет повторный ввод пароля разблокировки сейфов **после блокировки при действующем сеансе**. Вход в систему (с нуля, после выхода или истечения сеанса) по-прежнему требует пароль разблокировки сейфов и второй фактор.
- Пароль разблокировки сейфов и PIN нигде не сохраняются. На устройстве лежит только шифртекст ключа обёртки закрытого ключа; он открывается ключом, полученным из PIN **и** доли, которую сервер выдаёт после верного PIN.
- Сервер хранит проверочный хэш PIN и запечатанную долю, но не знает ни PIN, ни пароля разблокировки сейфов, ни ключей. После пяти неверных попыток подряд устройство удаляется: остаётся только пароль разблокировки сейфов.
- Смена пароля разблокировки сейфов, сброс по ключу восстановления и увольнение сотрудника удаляют все PIN-устройства. Выключение настройки администратором немедленно запрещает разблокировку PIN. Устройства видны в Настройках и удаляются по одному.

## Границы защиты

Короткий PIN держится на счётчике попыток сервера. Тот, кто одновременно украл устройство с шифртекстом, действующий сеанс и PIN, откроет Arklock; кто похитил только базу сервера, получит лишь запечатанные доли без шифртекстов устройств. Для устройств с повышенным риском не включайте PIN. Независимой проверки схемы не проводилось.
