# Выдача и отзыв доступа к сейфам

Документ описывает, что Arklock гарантирует при выдаче и отзыве доступа, и чего он гарантировать не может.

## Модель

- **Администратор** создаёт сейф, добавляет пользователей в группы и назначает группам доступ к сейфу с ролью
  (читатель, редактор, менеджер).
- **Сотрудник** ничего дополнительно не делает: ключ сейфа выдаётся ему автоматически клиентом администратора,
  у которого открыт ключ сейфа, при следующей загрузке сейфов.
- **Смена ключа** (ротация) — отдельная административная функция в настройках сейфа. Она необязательна и не требуется
  ни при одном изменении состава групп.

## Что гарантирует сервер (немедленно)

- Доступ к сейфу проверяется на сервере при каждом запросе: записи, вложения, ключи и история.
- После удаления пользователя из группы или группы из сейфа следующий запрос участника получает отказ. Новые
  шифртексты, новые версии ключа и вложения ему не выдаются.
- Выдача ключа ожидает клиента администратора; сервер не может выдать сейфовый ключ сам, потому что не знает ключей.

## Что не гарантирует никакая схема без смены ключа

Отзыв на сервере не отменяет знание, которое участник уже получил. Если бывший участник:

- знал ключ сейфа на момент отзыва и
- сохранил копию шифртекстов (например, скачал записи или резервную копию, которую смог расшифровать),

то эти копии он может расшифровать без сервера. Криптографически отозвать уже выданный ключ нельзя. Arklock не
создаёт ощущения полного отзыва: в интерфейсе после отзыва показывается пояснение, а не обещание.

## Что делает смена ключа

Смена ключа создаёт новую версию ключа сейфа, перешифровывает записи, ревизии и названия папок и выдаёт новый ключ
оставшимся участникам. Данные, сохранённые **после** смены, бывший участник не расшифрует. Данные, сохранённые до
смены, он по-прежнему может расшифровать, если сохранил их копии. Смена ключа — тяжёлая операция: она затрагивает
все записи сейфа. Поэтому она не выполняется автоматически.

## Рекомендации

- Для быстрого закрытия доступа достаточно удалить пользователя из группы или группу из сейфа: это действует сразу.
- Смену ключа выполняйте, если бывший участник знал секреты, которые нужно заменить: вместе с заменой паролей
  в самих сервисах. Смена ключа не заменяет смену паролей.
- Не храните у сотрудников выгрузки записей (CSV, JSON) без необходимости: зашифрованная выгрузка защищена только
  отдельным паролем.
