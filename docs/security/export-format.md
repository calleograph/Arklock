# Формат зашифрованного архива

Зашифрованный архив создаётся в браузере (Импорт и экспорт → Экспорт → «Зашифрованный архив»). Сервер видит только факт выгрузки (формат и число записей) и не получает ни пароль архива, ни содержимое.

## Как защищено

| Что | Как |
| --- | --- |
| Пароль | Создаётся браузером: 30 случайных знаков (прописные и строчные латинские буквы, цифры, спецсимволы; без похожих знаков, кавычек, пробелов и обратной косой). Источник случайности — `crypto.getRandomValues`, выбор знаков без смещения. Придумывать пароль вручную не нужно. |
| Вывод ключа | Argon2id: память 64 МиБ, 3 прохода, 1 поток. Пароль нормализуется NFKC. Соль — 16 случайных байт плюс метка `arklock-export`. Из результата HKDF выводит ключ шифрования (метка `arklock/v1/wrap`). |
| Шифрование | AES-256-GCM, случайный 96-битный одноразовый номер, тег 128 бит. Связанные данные: `arklock-export-v1`. Тег проверяется при расшифровке: любое изменение файла или неверный пароль дают отказ, а не искажённые данные. |
| Нижняя граница | При открытии архива параметры Argon2id ниже минимальных (память 19 МиБ, 2 прохода) отклоняются: подменой параметров ослабить защиту нельзя. |

## Структура файла

Файл — JSON:

```json
{
  "format": "arklock-encrypted",
  "version": 1,
  "kdf": { "memoryKiB": 65536, "iterations": 3, "parallelism": 1 },
  "salt": "<16 байт, base64url>",
  "data": "ak1.<nonce, base64url>.<шифртекст с тегом, base64url>"
}
```

Расшифрованное содержимое — JSON `arklock-export`:

- версия 2: `{ "format": "arklock-export", "version": 2, "exportedAt": "…", "vaults": [ { "name", "branches": [ { "id", "parentId", "name", "icon" } ], "entries": [ { …поля записи, "branchId", "attachments": [ { "name", "type", "data" } ] } ] } ] }`;
- версия 1 (прежние выгрузки одного сейфа) по-прежнему читается.

Поля записи: вид, название, логин, пароль, адрес, заметки, TOTP, дополнительные поля, метки, срок действия, связи, значок. Вложения лежат внутри записи в Base64 и защищены тем же шифрованием, что и всё содержимое архива.

## Восстановление вне Arklock

Если Arklock недоступен, архив открывается любой программой, которая умеет Argon2id и AES-GCM:

1. Прочитать `kdf`, `salt`. Соль Argon2id = `salt` ‖ UTF-8 строки `arklock-export`.
2. Argon2id(пароль NFKC, соль, m=`memoryKiB`, t=`iterations`, p=`parallelism`) → 32 байта.
3. HKDF-SHA-256 (ключевой материал — результат шага 2, соль — `salt`, info — `arklock/v1/wrap`) → 32 байта ключа.
4. `data` разделить по точке: `ak1`, одноразовый номер, шифртекст. Расшифровать AES-256-GCM, связанные данные `arklock-export-v1`.
5. Результат — UTF-8 JSON выше.

## Открытые форматы

JSON и CSV из того же раздела **не зашифрованы**: пароли в них лежат открытым текстом. Поэтому выгрузка требует отметки «Я понимаю риск». CSV хранит только название, логин, пароль, адрес, заметки, TOTP, папку и метки; дополнительные поля и вложения в нём не сохраняются.

## Чего в журнале нет

В журнал действий попадают пользователь, формат («encrypted», «json», «csv») и число записей. Пароль архива, имена записей и содержимое не записываются.
