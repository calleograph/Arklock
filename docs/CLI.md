# Командная строка и токены API

Консольный клиент `arklock` работает на вашем компьютере. Пароль разблокировки сейфов превращается в ключи локально; серверу уходит только токен и шифртекст. Токен API **не открывает данные** — у него нет ключей.

## Токены API

Создаются в веб-интерфейсе: «Безопасность» → «Токены API и командная строка». Для создания нужен пароль разблокировки сейфов (и код второго фактора, если он включён). Токен показывается один раз; сервер хранит только его SHA-256.

- **Только чтение** — разрешены только GET-запросы.
- **Чтение и запись** — разрешены также изменения в хранилищах.
- Срок действия в днях (0 — без срока), отзыв в любой момент, время последнего использования.
- Токену недоступно: управление учётной записью, сеансы, второй фактор, другие токены, административные маршруты (ответ 403 `token_not_allowed`).
- Если политика требует двухфакторную аутентификацию, а у владельца она не настроена, токены тоже не работают.

## Установка клиента

Клиент входит в репозиторий (`apps/cli`). Сборка и запуск:

```bash
npm ci && npm run build
node apps/cli/dist/main.js help        # или: npm link -w @arklock/cli  → команда arklock
```

## Команды

| Команда                                                                           | Что делает                                            |
| --------------------------------------------------------------------------------- | ----------------------------------------------------- |
| `arklock config --server URL --token akt_…`                                       | сохранить адрес и токен (файл доступен только вам)    |
| `arklock login --server URL --email ACCOUNT`                                      | войти по имени пользователя или почте и коду второго фактора |
| `arklock whoami`, `arklock vaults`                                                | кто вошёл, какие хранилища доступны                   |
| `arklock list [-q текст] [--vault имя] [--json]`                                  | список записей (с путём папок)                        |
| `arklock get <запись> [--field password\|username\|url\|notes\|totp\|имя] [--json]` | прочитать запись или поле                             |
| `arklock totp <запись>`                                                           | текущий код TOTP                                      |
| `arklock add --title T [--username U] [--password P \| --generate] [--folder A/B]` | создать запись (нужен токен с записью)                |
| `arklock generate [--length N] [--phrase]`                                        | пароль или парольная фраза                            |

Пароль разблокировки сейфов берётся из `ARKLOCK_PASSWORD` или запрашивается в терминале (без эха). Адрес и токен можно задать переменными `ARKLOCK_SERVER` и `ARKLOCK_TOKEN`; код второго фактора для `login` — `ARKLOCK_MFA_CODE`. Файл настроек: `~/.config/arklock/config.json` (права 600, каталог `ARKLOCK_CONFIG_DIR` переопределяет).

## Защита

- Подписи выданных ключей хранилищ проверяются по журналу ключей; цепочка хэшей журнала проверяется при каждом запуске.
- Клиент запоминает последнее увиденное состояние журнала ключей и отказывается работать, если оно изменилось «задним числом».
- Пароль и расшифрованные данные не отправляются на сервер (проверено тестом, который просматривает все тела запросов).
