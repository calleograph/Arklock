# Диагностика и обслуживание

Сценарии ниже работают из командной строки. В веб-панели есть раздел «Администрирование → Система → Диагностика»: состояния проверок со ссылкой на нужную настройку.

| Сценарий                | Назначение                                                                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scripts/status.sh`     | версии, контейнеры, место, последние копии                                                                                                              |
| `scripts/verify.sh`     | контейнеры и healthcheck, API, версия сборки, соответствие схемы БД миграциям, права файлов, непубликуемость БД, работа без root, место (код 1 при ошибках) |
| `scripts/preflight.sh`  | требования перед установкой или обновлением                                                                                                             |
| `scripts/smoke-test.sh` | быстрые проверки основных сценариев (без изменения данных)                                                                                              |
| `scripts/logs.sh`       | журналы контейнеров с маскированием токенов и паролей                                                                                                   |
| `scripts/diag.sh`       | диагностический пакет: секреты маскируются, содержимое БД и ключи не включаются                                                                         |
| `scripts/repair.sh`     | безопасные исправления: каталоги, права, проверка БД; перезапуск неисправных контейнеров — только с `--restart`                                         |

`repair.sh` никогда не очищает БД, не удаляет тома, не пересоздаёт секреты и ключи и не сбрасывает данные пользователей.

Журналы обновлений: `DATA_ROOT/logs/updates.log`.
