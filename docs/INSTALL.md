# Установка

Статус проверки: установка, повторный запуск, профиль shared-host, зашифрованное резервное копирование и восстановление автоматически проверяются в CI на чистом раннере Ubuntu 24.04 (см. `.github/workflows/ci.yml`, задачи `installer` и `shared-host`). **Debian 12 и реальный сервер с перезагрузкой пока не проверялись.**

## Требования

- Ubuntu 24.04 LTS или Debian 12, архитектура x86_64 или aarch64, root-доступ.
- От 1 ГБ оперативной памяти, от 3 ГиБ свободного места в каталоге данных.
- Доступ в интернет (пакеты, Docker, репозиторий). Для закрытого контура — см. раздел «Ограничения».

## Установка одной командой

Рекомендуемый способ — скачать установщик релиза, проверить его и запустить:

```bash
curl -fsSLO https://raw.githubusercontent.com/calleograph/arklock/v0.1.0/install.sh   # подставьте тег релиза
less install.sh                                                                          # просмотрите, что будет выполнено
sudo bash install.sh --ref v0.1.0
```

Установщик не исполняет содержимое ветки `main`: по умолчанию берётся последний релизный тег, а установка непомеченной ветки требует явного `--allow-unreleased`.

> Пока релизов нет, а репозиторий закрыт, установка выполняется из клона: `git clone … && sudo ./install.sh`.

## Что делает установщик

1. Проверяет ОС, архитектуру, память, место, права.
2. Определяет профиль: **standalone** (отдельный сервер) или **shared-host** (на сервере уже работают другие приложения). Выбор можно задать `--profile`.
3. Устанавливает недостающие пакеты и Docker Engine с Compose Plugin — только в профиле standalone.
4. Подбирает свободный порт на `127.0.0.1` (8080 и выше), создаёт каталоги, файл конфигурации `/etc/arklock/arklock.env` (права 600) со случайными секретами и ключ резервного шифрования `/etc/arklock/backup.key`.
5. Собирает образ, запускает PostgreSQL и приложение отдельным compose-проектом, применяет миграции.
6. Устанавливает помощника обновлений (служба systemd), выполняет `scripts/verify.sh` и печатает адрес и **одноразовый код настройки** для создания первого администратора.

Повторный запуск безопасен: секреты, тома и данные не пересоздаются.

### Профиль shared-host

Установщик **не устанавливает** Docker и пакеты, не меняет Nginx, чужие контейнеры, чужие порты и настройки системы. Занятый порт не занимается (`--port` на занятый порт — отказ без побочных эффектов). Если Docker или утилиты отсутствуют, установщик сообщает, что нужно поставить вручную.

## Параметры

`--profile`, `--dir` (по умолчанию `/opt/arklock`), `--data` (по умолчанию `/var/lib/arklock`), `--config`, `--project`, `--port`, `--url`, `--ref`, `--repo`, `--allow-unreleased`, `--yes`, `--dry-run`. Подробности: `./install.sh --help`.

## Первый вход

Откройте адрес из итога установки, создайте первую учётную запись, введите код настройки (он хранится в `arklock.env` как `BOOTSTRAP_TOKEN` и нужен только для первой записи), сохраните показанный **ключ восстановления**.

## HTTPS и reverse proxy

Приложение слушает только `127.0.0.1`. Для доступа по сети поставьте reverse proxy с HTTPS, передавайте `X-Forwarded-For` и `X-Forwarded-Proto`, укажите число прокси в `TRUSTED_PROXY_HOPS`. Автоматическая настройка Nginx установщиком **ещё не реализована**.

## Ограничения

- Образ собирается на сервере из исходного кода; публикация образов в GHCR и проверка digest — планируются вместе с релизами.
- Административная панель (ресурсы, контейнеры, журналы, резервное копирование, диагностика, LDAP, SMTP) **не реализована**; реализован раздел «Обновления» (см. [UPDATE.md](UPDATE.md)).
- Установка в закрытом контуре (локальный registry, офлайн-пакет) не реализована.
