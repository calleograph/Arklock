# Состояние функций (версия 1.18.0)

Статусы: **Реализовано и проверено** — есть код и автоматическая проверка (тесты API/браузера); **Частично** — работает не полностью, граница указана; **Не реализовано**; **Архитектурное ограничение** — следует из модели шифрования, а не из недоработки; **Неприменимо**.

| Область | Статус | Подтверждение и границы |
| --- | --- | --- |
| Единые термины, подсказки «i», раздел «Помощь», сообщения об ошибках (RU/EN) | Реализовано и проверено | Тест словарей, браузерный прогон на 390 и 820 px во всех темах. Ручная проверка каждого экрана во всех ролях не проводилась |
| Административные роли пользователям и группам (в том числе доменным) | Реализовано и проверено | `roles.test.ts`, браузерный сценарий. Роль не открывает содержимое сейфов |
| Отдельная роль «главный администратор» помимо полного администратора | Частично | Полный администратор и делегированные роли есть; выделенной роли с запретом на содержимое и своим набором правил нет |
| Корпоративное восстановление (офлайн-пакет, аудит, подключение сейфов) | Частично | Работает для заранее подключённых сейфов; замена пакета через переподключение сейфов (`corporate-recovery-replacement.test.ts`, браузерная проверка); получатель один; независимой проверки нет |
| Увольнение сотрудника | Реализовано и проверено | `offboarding.test.ts`, браузерный шаг. Смену ключа сейфа и паролей во внешних системах выполняют люди |
| LDAP/AD: профили, сопоставление групп, плановая сверка, отключённые, недоступность каталога | Реализовано и проверено | `ldap.test.ts`. Нет SCIM, переноса идентичности при смене DN, вложенных групп; уведомление о риске хранителя без положительного теста |
| Права на папки и записи: наследование, явный запрет, эффективные права | Реализовано и проверено | `object-access.test.ts` |
| Криптографическая изоляция отдельной записи внутри сейфа | Архитектурное ограничение | Ключи записей обёрнуты общим ключом сейфа; для независимых границ доверия нужны разные сейфы |
| Выдача ключей и состояния «ключ ожидается / выдан» | Реализовано и проверено | Тесты рабочего пространства и сейфов; сервер не может выдать ключ сам |
| Личные сейфы выключены по умолчанию, исключения, сохранение данных | Реализовано и проверено | `personal-lockers.test.ts` |
| Политики паролей по уровням | Частично | Проверяет веб-клиент; сервер не видит открытых паролей и не может проверить их у стороннего клиента |
| PIN и доверенные устройства | Реализовано и проверено | `pin.test.ts`, браузерный сценарий. Схема без независимого аудита; PIN действует только при активном сеансе |
| Несколько провайдеров проверки утечек | Реализовано и проверено | `security.test.ts`. Только формат HIBP range |
| Вебхуки | Реализовано и проверено | `webhooks.test.ts`. Нет очереди на диске |
| Автоматизация: токены API, CLI | Реализовано и проверено | `tokens.test.ts`. Токены не расшифровывают секреты: сервер их не знает |
| Правила автоматизации (триггеры, сценарии) | Не реализовано | |
| Расширение браузера | Частично | Chromium/Firefox, сборка в CI; в магазинах не опубликовано |
| Резервное копирование и восстановление на той же машине | Реализовано и проверено | Задача `installer` в CI: после уничтожения БД та же запись расшифровывается |
| Восстановление на другом чистом сервере | Не реализовано | Процедура описана в docs/BACKUP_AND_RESTORE.md, автоматически не проверяется |
| Обновление через браузер | Реализовано и проверено | `updates.spec.ts`, `live-update.spec.ts`. Один непонятный сбой живого сценария зафиксирован в PROJECT.md |
| Нативные мобильные приложения, SCIM | Не реализовано | |
