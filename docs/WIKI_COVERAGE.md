# Вики: план, матрица покрытия и отчёт о пробелах

Версия вики 1.80.0, ветка `main`, коммит основы аудита `b10c36c`, дата 2026-10-26. Исходники — каталог `wiki/`; порядок публикации — страница «Сопровождение вики». Проверка: `node scripts/check-wiki.mjs`.

Тип продукта: веб-сервис для самостоятельного размещения с консольным клиентом и расширением браузера. Аудитории: потенциальный пользователь, сотрудник, системный администратор, администратор доступа, специалист по безопасности, интегратор, разработчик, сотрудник поддержки.

## Отчёт о пробелах

**Не удалось подтвердить:**

- Работу команд установки, копий, обновления и HTTPS на чистом сервере в среде автора вики: в CI они проверены на Ubuntu 24.04, автор их не запускал (помечено на страницах).
- Работу с реальными Active Directory, провайдерами SSO и SAML, S3 (кроме Scality CloudServer) и SMB (кроме Samba): уровень 4 не достигнут ни для одной интеграции.
- Установку на Ubuntu 22.04 и Debian 12.
- Получение сертификата Let's Encrypt и продление.
- Нагрузочные характеристики сотен одновременных пользователей.

**Нужно от автора проекта:**

- Включить вики репозитория и сохранить первую страницу вручную (репозиторий вики пока не существует), затем выполнить публикацию по странице «Сопровождение вики».
- Решить, нужен ли каталог `docs` с GitHub Pages вместо вики, если требуется ревью документации в CI.
- Подтвердить формулировку про коммерческое использование у юриста: страница лицензии не является юридической консультацией.

**Скриншоты:** сделаны с текущей сборки 1.80.0 на вымышленных данных: рабочее пространство, первая регистрация, обзор администрирования, вкладка «Доступ». Не сделаны: импорт и экспорт, мастер «Подразделения», обновления, копии, LDAP и SSO (скрипт `scripts/screenshots.mjs` частично устарел после перестройки меню администрирования: падает на вкладке настроек безопасности; обновление скрипта не входило в задачу).

**Команды, которые не запускались:** все команды установки, `scripts/*.sh`, `rsync` и `git push` публикации, команды CLI.

**Что не проверено:** орфография проверена только чтением и проверкой структуры скриптом, автоматической проверки орфографии нет; отображение Mermaid и кириллических имён страниц на GitHub проверяется после первой публикации; независимая сверка проверяющим агентом не выполнялась.
