# Выбор лицензии: техническая оценка

Статус: **принято решение — AGPL-3.0-only** (решение владельца проекта, 2026-10-11). Текст лицензии — в корневом файле `LICENSE` (оригинальный текст GNU без изменений). Документ сохранён как обоснование; он не является юридической консультацией.

## Условия, не зависящие от выбора

- Продукт полностью бесплатный: без платных редакций, лицензионных ключей, ограничений по числу пользователей и записей.
- Продуктивные зависимости (образ и веб-клиент) имеют только разрешительные лицензии: MIT, ISC, BSD-2/3-Clause, Apache-2.0, BlueOak-1.0.0. Проверка: `npm run check:licenses` (выполняется в CI, падает при copyleft и неизвестных лицензиях).
- Обе рассматриваемые лицензии совместимы с этим набором зависимостей.

## Сравнение

| Критерий                                                 | Apache-2.0                                                                    | AGPL-3.0                                                                                                           |
| -------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Использование внутри организации                         | свободно                                                                      | свободно                                                                                                           |
| Закрытый форк, развёрнутый как сетевой сервис (SaaS)     | допускается без раскрытия изменений                                           | запрещён: изменённая версия, доступная по сети, обязана предоставить исходный код пользователям                    |
| Встраивание в закрытые продукты                          | допускается                                                                   | требует открыть производный продукт под AGPL                                                                       |
| Патентная лицензия от авторов                            | явная                                                                         | явная (через GPLv3)                                                                                                |
| Принятие в корпоративной среде                           | обычно без ограничений                                                        | часть организаций запрещает AGPL-ПО политикой; для самостоятельного развёртывания без изменений это не мешает      |
| Совместимость с будущими коммерческими планами владельца | не мешает                                                                     | владелец как единственный правообладатель может выдавать дополнительные лицензии, если вкладчики передадут права   |
| Защита от «забирания» проекта конкурентом                | слабая                                                                        | сильная в части сетевых сервисов                                                                                   |
| Требования к вкладчикам                                  | достаточно DCO; CLA не обязателен                                             | при желании сохранить возможность смены лицензии нужен CLA или передача прав                                       |

## Практические различия для Arklock

- Продукт — сетевой сервис с самостоятельным развёртыванием; именно для таких программ создавалась AGPL-3.0 (раздел 13). Если важно, чтобы улучшения, выпущенные кем-то как хостинг-сервис, возвращались сообществу, подходит AGPL-3.0.
- Если приоритет — максимальное внедрение в организациях и возможность встраивания (например, в закрытые корпоративные платформы), подходит Apache-2.0.
- Для менеджера паролей прозрачность кода особенно важна для доверия; обе лицензии её обеспечивают. AGPL дополнительно гарантирует прозрачность изменённых публичных сервисов.

## Выполнено

1. `LICENSE` — полный текст AGPL-3.0.
2. `license: AGPL-3.0-only` во всех манифестах `package.json`; описание в README.
3. Проверка в CI (`node scripts/check-licenses.mjs`): допускаются только разрешительные лицензии зависимостей, `LICENSE` и манифесты согласованы.
4. Совместимость: все продуктивные зависимости (MIT, ISC, BSD-2/3-Clause, Apache-2.0, BlueOak-1.0.0) совместимы с AGPL-3.0 (Apache-2.0 — односторонне, с GPLv3 и AGPLv3).

## Вклад в проект

Входящие изменения принимаются на тех же условиях (AGPL-3.0-only) с подтверждением происхождения (Developer Certificate of Origin, подпись `Signed-off-by`). Лицензионных ключей, серверов активации и телеметрии лицензирования в проекте нет и не будет.
