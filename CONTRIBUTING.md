# Участие в разработке

1. Node.js 24+, `npm ci`.
2. Перед коммитом: `npm run format && npm run lint && npm run build && npm run typecheck && npm test`.
3. Секреты, `.env`, дампы БД и частные адреса в репозиторий не добавляются. Проверка: `npm run check:private`.
4. Каждое изменение поведения сопровождается тестом и обновлением `PROJECT.md`, `HISTORY.md` и, для видимых изменений, `CHANGELOG.md`.
5. Версия — SemVer, единственный источник — файл `VERSION`.
6. Криптографический код: никаких собственных примитивов; изменение формата — только с новой версией формата и тестами совместимости.
7. Лицензия проекта — AGPL-3.0-only. Отправляя изменения, вы подтверждаете право предоставить их на этих условиях (Developer Certificate of Origin: добавляйте `Signed-off-by` через `git commit -s`).
